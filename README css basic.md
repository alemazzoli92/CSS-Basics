# Travel Destination Website

A multi-page travel destination website built with HTML5 and CSS3.

The project focuses on creating a visually styled travel website with custom typography, landscape background images, related destinations and navigation between multiple pages.

## Technologies

- HTML5
- CSS3
- Google Fonts
  - Prata
  - Montserrat
- GitHub Pages

## Features

- Multi-page website structure
- Custom typography using Google Fonts
- Landscape background images
- Styled headings and text sections
- CSS gradients
- Custom spacing, borders and rounded corners
- Related destinations navigation
- Visited link styling
- Navigation between interconnected HTML pages
- Footer with homepage navigation

## Pages

The website includes multiple destination pages:

- Lago Smeraldo
- Lago di Tovel
- Canyon Rio Sass
- Castel Thun
- San Romedio
- Passo della Mendola
